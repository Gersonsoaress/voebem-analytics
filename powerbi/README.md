# 📊 Power BI — Voebem Analytics

Esta pasta contém a etapa de visualização e análise de dados do projeto **Voebem Analytics**.

Os dados foram preparados no **Databricks**, utilizando a arquitetura Medalhão (Bronze, Silver e Gold), e a camada Gold foi estruturada para consumo analítico no **Power BI**.

## Objetivo do Dashboard

Desenvolver um dashboard interativo para análise das operações aéreas, permitindo explorar indicadores e informações relevantes dos voos.

## Tecnologias

- Microsoft Power BI
- Power Query
- DAX
- Databricks
- SQL
